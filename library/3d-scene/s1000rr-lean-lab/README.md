# S 1000 RR · K67 — Lean Laboratory

把文件夹里的 `最新能用.glb` 做成一个可以上手操作的三维展示台。

## 运行

双击 **`start.cmd`**（或 `启动.cmd`，内容相同），浏览器会自动打开。
关掉那个黑色命令行窗口就停止服务。

`start.cmd` 只是去调 `serve.py`：自动挑一个没被占用的端口（8899 起，往上找到 8929），
起服务、开浏览器、并且给所有响应加 `Cache-Control: no-store`，避免改了文件还看到旧版。

必须走 HTTP —— 浏览器不允许 `file://` 页面 fetch `.glb`，直接双击 `index.html` 会永远卡在载入界面。

> 两个 `.cmd` 名字不同是有原因的：中文文件名在部分终端里传参会因为代码页转换而失败
> （Explorer 双击没问题）。想在命令行里敲，用 ASCII 名的 `start.cmd` 更保险。
> 也可以完全跳过批处理，直接 `python serve.py`。

## 倾角是怎么算出来的

不是拍脑袋填的数，是从这台网格量出来的：

1. 98 万个顶点全部投影到横截面（XY 平面），按 2048 个 x 分箱取每列最低点，得到一条**下包络**。
   因为任何侧倾角的 cos 都为正，车体最低点必定落在这条包络上，所以这张 2000 来点的小表就能精确回答任意角度。
2. 从接地点向两侧走，直到轮廓抬高超过 100 mm —— 这一段是**轮胎接地带**（实测半宽 110 mm）。
3. 侧倾时车绕接地线滚，接地点沿胎冠移动，车身随之抬起。抬升量按接地带实时求解，所以轮胎永远贴地、不会陷进地面。
4. 排除接地带后，求车身第一次触到地面的角度 —— 就是**倾角上限**：左 43.4°、右 44.4°。
   左右不同是因为这台车本身不对称（排气尾段在左侧）。滑杆到这里就压不动了。

## 拆解件

TEARDOWN 用的是另一份文件 `拆分.glb` —— 同一台车的第二次扫描，被算法按材质与连通性
切成 **11 个独立网格**（`part_0` … `part_10`，共 152 万面），不带任何贴图，只有一段
分割用的顶点色（纯色 ID，不是车漆，页面里已忽略）。

### 没有贴图，怎么渲染

这份文件 `images: 0`，连 UV 都没有，所以贴不了车漆——但**镜面反射根本不需要 UV**，
只要法线加环境贴图就够了。所以拆解件默认走 CHROME，跟全站默认完全一致；
另外两档 ALLOY（拉丝铝，高光散开、形体边界最好读）和 CLAY（哑光素模）。
四种环境光同样生效。

法线也是缺的，载入时用 `computeVertexNormals()` 现算。

分块来自分割结果，不是原厂零件表，有几处能明显看出来：

- **05 号**同时装着排气尾段和手把控制组 —— 两处材质相同，颜色上分不开，被归成一块。
  所以它的抽出方向是「整块朝侧面推」，这样两团都不会插进别的零件里。
- **02 号**（发动机 + 车架 + 后摇臂）位移设为 0，当骨架用。
- 其余 9 块的方向是手写的。用「从质心向外辐射」那种算法在摩托车上不成立 ——
  车是细长的，所有零件的 x 都接近 0，散出来会全挤在一条线上。

拾取用的是**包围盒**而不是三角形精确求交：11 个盒子几微秒就测完，
而 152 万面的精确求交单次要 115 ms，挂在 pointermove 上直接卡死。
散开状态下盒子彼此分离，判定准确；合拢时会有重叠，那时用左边列表点选更准。

模型是**进入该章节时才按需加载**的（5.0 MB），不占首屏。

## 模型是怎么压的

原始 `最新能用.glb` 是 **80.6 MB**，直接丢进网页会等到天荒地老。

```
80.6 MB  原始（4K PNG ×3 + 未压缩几何）
60.6 MB  贴图降到 2K
50.5 MB  贴图转 WebP q94
10.8 MB  几何 meshopt 压缩          ← 本页实际加载
```

**7.8× 压缩，三角面一个没少**（1 494 872 个全在）。
另外准备了 `bike-lite.glb`（3.9 MB，简化到 41.8 万面 + 1K 贴图），移动端或低端设备自动加载。

拆解件同样处理：`拆分.glb` **29.9 MB → 5.0 MB**（6×，152 万面全保留），
`parts-lite.glb` 1.5 MB。

## 注意

- 需要 WebGL2。1.49 M 面单 draw call，桌面独显上跑满 120 fps；
  如果连续三次采样低于 42 fps，会自动关掉地面反射。
- 移动端布局已经写好（控制台变成底部两列面板），但**没有在真机窄屏上验证过**。
- DATA 页的「实测」取自当前渲染的网格，按车长 2073 mm 归一化；
  「参考」是 S 1000 RR (K67) 的公布参数，仅供对照。
