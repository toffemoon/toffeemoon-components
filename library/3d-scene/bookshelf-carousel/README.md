# 书架轮播 · Bookshelf

three.js 3D 书架轮播组件。所有书持续渲染在书架里,未选中的以竖直书脊排列,当前那本**绕自己的书脊为铰链**从书架中向外展开,以 3/4 视角悬在书架前方 —— 封面和左侧书脊同时可见。

**书与书之间是一段完整的开合动画**,而且分两段搭接:上一本先转回书脊、再推回书架;下一本先探出书架(书脊朝外、比旁边亮)、再绕书脊转开封面。两者的"抽出"段首尾重叠,交接时画面上始终有书在动,不会出现整排平齐的死寂。

点箭头是把这段动画正常播一遍;拖动划过很多本,就是同一段动画被加速连播,每经过一本都真的开合一次。

参考《绝区零》录像带架。为个人博物馆站的"书架 = 项目 / 经历"做的,也可单独用。

## 运行

```bash
npm install
npm run dev      # http://localhost:5189
npm run build    # 单文件产物 dist/index.html
```

## 用

```js
import { Bookshelf } from './src/bookshelf.js';

const shelf = new Bookshelf(containerEl, {
  rows: [
    { id: 'projects', label: '项目', items: [
      { id: 'a', title: 'Ripple', subtitle: '…', code: 'PRJ-01', color: '#1f9d8a', cover: '/covers/ripple.jpg' },
      { id: 'x', locked: true },          // 未开放填充位
    ]},
    { id: 'experience', label: '经历', items: [ /* … */ ] },
  ],
  switchMode: 'slide',   // 'slide' 镜头在上下排之间滑;'swap' 原地替换
  loop: true,            // 书架首尾相接,可以一直往一个方向翻
  touchAction: 'none',   // 宿主页需要竖向滚动时传 'pan-y'
  onChange: (s) => { /* s = { rowIndex, row, index, item, opened, moving, transitioning, canPrev, canNext } */ },
  onOpen: (item) => { /* 停稳自动翻开时 */ },
  onActivate: (item) => { /* 翻开后再点 / Enter:进详情,宿主接管 */ },
});

shelf.next(); shelf.prev(); shelf.select(i);   // 滑到某本并停住,停稳后自动翻开
shelf.open(); shelf.close();                   // 手动控制,一般不用
shelf.switchRow(1); shelf.nextRow(); shelf.prevRow();
shelf.dispose();
```

内置交互:拖动 / 滚轮连续滑,松手带惯性吸附到最近一本;点别的书滑过去;翻开后再点进详情;← → 逐本,Enter 进详情,Esc 合上,↑ ↓ 换排。未开放的书会被滑过但不会停在上面。

## 结构

```
src/poses.js       姿态常量 + 时间轴参数 —— 对照参考视频微调只改这里
src/bookshelf.js   组件本体:铰链排布、GSAP 时间轴、镜头、灯、交互
src/textures.js    程序化贴图:书脊(按实际厚高比出图,中文竖排 / 西文转 90°)、封面占位、背板网格
src/post.js        后处理:分层虚化(当前书单独一层不糊)+ 暗角 / 颗粒 / 扫描线
src/main.js        演示页:数据 + UI 外壳
index.html         演示页
```

调参:动效在 `src/poses.js`(`EXT_*` / `SWING_*` 两段曲线的跨度与搭接、`metrics()` 里的 `ext*` 探出态、`T` 时长缓动惯性、`OPEN_*` 展示态角度);排布与景深在 `src/bookshelf.js` 的 `DEFAULTS`(`gap` / `tiltRange` / `depthJitter` / `focusRange` / `minBlur*`)。

## 怎么做到的

- **一个连续量**:组件只有 `pos`(浮点索引)。`pos = 6` 是第 6 本完全展开,`6.5` 是它和第 7 本之间。每本书的**展开度** `openness ∈ 0..1` 只由 `t = pos - index` 决定,姿态就是"收纳态 ↔ 展开态"按 openness 插值 —— 中间值天然是铰链开合的任意一帧。
  - 拖动 = 直接改 `pos`,等于用手擦洗这段动画;
  - 点箭头 / 键盘 / 滚轮 = 用 GSAP 把 `pos` 补间到下一个整数。
  两者跑的是同一套计算,没有第二条代码路径,所以"划过很多本"必然等于"这段动画被加速连播"。
- **铰链**:每本书是 `pivot`(Group)+ `mesh`(Box)。pivot 落在书的**左前竖棱**,也就是书脊那条边;mesh 相对它固定偏移 `(+T/2, 0, -D/2)`。转 `pivot.rotation.y` 就是"绕书脊开合",书脊留在原位、封面像门一样甩开。`rotY = 0` 是收纳态,展示态是 `-π/2 + 0.42`(留 24° 让书脊在左侧仍可读)。
- **两段式**:姿态拆成 `extend`(抽出:前推、略放大点亮、轻微歪,书脊始终朝镜头)和 `swing`(转开:绕书脊把封面甩向镜头)。swing 的跨度包在 extend 内部,于是收回 = 先转回书脊再推回架里,展开 = 先探出架子再转开封面。相邻两本的 extend 首尾搭接(旧书 p=0.45 归零,新书 p=0.32 就开始探出),交接不断档。
- **变速**:一次切换里三件事节奏不同,不能用一条均匀的 easeInOut —— 旧书收回中速、书脊横移交接最快、新书探出转开最慢。`stepEaseFn` 把线性时间重映射成 pos 进度:前 30% 时间加速冲到 pos 的 38%(交接点),后 70% 时间长长地减速走完剩下的 62%。实测一次切换 ≈950ms,中段 197ms 走 0.385、末段 424ms 只走 0.272,快慢比约 2.6:1。
- **走多本的时长**:`stepDur × dist^0.55`,划过 5 本不等 5 倍时间。
- **拖动阻尼**:`dragScale` 决定要拖过一本书宽度的几倍才滑一本(默认 2.6 ≈ 118px/本),大了更钝、不容易误滑。
- **景深**:场景层带深度纹理,合成时按每个像素的深度在"锐版"和"糊版"之间连续插值(`coc = |dist - focus| / focusRange`),焦平面跟着最突出的那本走。所以背景是**近处能读出书脊字、越远越糊成色块**的连续渐变,不是一刀切两档。当前书另外渲到全分辨率 MSAA 透明层,按预乘 over 盖在最上面,永远绝对清晰。
- **书架排布**:书之间留 `gap`(能看到缝隙后面)、倾斜角 ±7.5°、前后 `depthJitter` 错开,厚度和间距都带随机 —— 参考图里书是一块块分开的板,不是密排贴在一起。
- **循环**:`loop: true` 时书架首尾相接。`pos` 可以无限增减,每本书取离 `pos` 最近的那一圈显示(`t` 按 n 取模、`x` 加整圈宽度偏移),所以能一直往一个方向翻。
- **拖动**:`dragMode: 'free'`(默认)拖多远滑多少本,松手按速度甩出去若干本再吸附;`'step'` 是一次手势一本(阈值 48px)。滚轮按一本节流(260ms)。
- **换排**:清晰的选中层先淡出、整帧糊到 1,峰值处换排并落到中间那本,再退回常态、选中层淡入。`slide` 模式下镜头 y 同时滑到新排。
- **省显存**:封底纯色、未开放的书不出封面、封面按需生成并只保留最近 5 张(LRU);竖屏按水平视角反推 fov(`hFov`)。
- **减少动态效果**:`prefers-reduced-motion` 下切换简化成 0.18s 的位姿过渡,仍保留明确的当前书状态。
- **书脊文字**:`CanvasTexture`,画布按书的实际厚高比开,避免拉伸;标题含中日韩字就单字竖排,否则整行转 90°。
- **翻开**:四元数目标位姿(yaw 把封面转向镜头 → pitch 后仰 → tilt 绕视轴歪),slerp 阻尼过去,不用补间库。

## 验证

`npm run dev` 起来后用 Playwright(`--use-angle=swiftshader`)核对过:入场 / 拖动 / 惯性吸附 / 换排溶解 / swap 模式点书 / 竖屏 / 箭头真点击 / 铰链时间轴逐时刻姿态 / prev 镜像。

看编排最直接的手法是擦洗:控制台里 `shelf.pos = 6.2` 停在"旧书探出但已转回书脊",`6.6` 停在"新书探出、还没转开",`6.8` 停在"转开 85%"。实测 pos 6.0→7.0:

| pos | 旧书 抽出/转开 | 新书 抽出/转开 |
|---|---|---|
| 6.00 | 1.00 / 1.00 | 0 / 0 |
| 6.20 | 0.65 / 0 | 0 / 0 |
| 6.42 | 0 / 0 | 0.38 / 0 |
| 6.60 | 0 / 0 | 0.80 / 0 |
| 6.80 | 0 / 0 | 0.97 / 0.85 |
| 7.00 | 0 / 0 | 1.00 / 1.00 |

拖动轨迹连续经过每个整数,松手落在最近的可停位。

量取景:把 mesh 包围盒八个角投影到 NDC。桌面静止态书占屏 36.7%–65.7%(中心 51.2%),竖屏 24.6%–79%(中心 51.8%)。

内置浏览器面板不合成 WebGL,看效果要开真浏览器。
