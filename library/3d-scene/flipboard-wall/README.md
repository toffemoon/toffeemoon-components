# 翻板墙

地铁站那种整面网格翻板广告墙的 three.js 复刻。一面墙由上千块独立的发光面板组成,每块各自翻转,靠时序的错落拼出整墙换画面的效果。

```bash
npm install
npm run dev
```

打开后右上角是控制面板,所有参数实时可调。

## 两个设计决定

**翻转在顶点着色器里做。** 每格通过 instanced attribute 拿到自己的延迟值,CPU 每帧只更新一个 `uTime`。整面墙是一个 `InstancedMesh`,不逐格算矩阵,所以上千格也能满帧,调参能实时响应。

**不切图。** 整张源图当一张纹理,每格按自己的 `(列, 行)` 算 UV 偏移去采样。面板用 Box 而不是 Plane:`+Z` 面永远采样图 A,`-Z` 面永远采样图 B,四个侧面走金属框色。翻 180° 之后 `-Z` 面自然朝向观众,换图就发生了,不需要任何额外逻辑,也不需要预处理素材。

## 目录

| 文件 | 职责 |
|---|---|
| `src/config.js` | 所有默认参数。改默认值只改这里 |
| `src/wall/timing.js` | 时序引擎。纯函数:格子坐标 → 0..1 延迟。加新节奏在这儿加 |
| `src/wall/geometry.js` | 单格几何 + 整墙排布 |
| `src/wall/material.js` | shader:顶点翻转、双面 UV 采样、灯箱与玻璃质感 |
| `src/wall/index.js` | 装配成墙,推进翻转周期 |
| `src/scene/` | 相机、顶部灯带与背板、后期辉光 |
| `src/textures/placeholder.js` | 占位纹理生成 + 自有素材加载 |
| `src/ui/panel.js` | 控制面板 |

## 时序模式

效果好不好看,九成取决于时序,不取决于渲染精度。所以 `timing.js` 是独立的纯函数模块,方便单独试和对比。

内置八种:随机、对角波浪、中心扩散、中心收拢、列扫、行扫、分组批次、涟漪。

配合两个参数用:

- **全墙散布** — 第一格到最后一格的时间差。调大变慢、变"散",调小整墙近似同时翻
- **随机抖动** — 往规则模式里掺随机。规整的模式配 0.15 左右会显著自然,给到 1 就退化成纯随机

想加新节奏,在 `MODES` 里加一个 `(col, row, cols, rows, seed) => 0..1` 的函数即可,归一化和抖动混合是外面统一做的。

## 换素材

见 `public/README.md`。两张同比例的图命名 `a.jpg` / `b.jpg` 丢进 `public/`,刷新生效。没放就用程序生成的占位图。

没放自有素材时,控制台会有几条 404 —— 那是在探测 `a.jpg` / `a.png` / `a.webp` 有没有存在,属于预期行为,不影响运行。

## 已知边界

- **只有两个状态。** 现场那种三面翻广告牌是三态循环,这里是正反两面互切。要做多态得把 Box 换成三棱柱,几何和 UV 都要重写
- **中间态是干净的翻转。** 视频里那种"撕纸卷曲"的乱,如果原本就是屏幕播的转场,这套几何翻转还原不了,得另外叠一层碎裂着色器
- **格子多了之后源图分辨率是瓶颈。** 不是渲染性能,是每格分到的像素数,见 `public/README.md`
