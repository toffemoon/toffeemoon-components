# 换成自己的素材

把两张图放进这个目录:

- `a.jpg` — 起始画面(翻转前看到的)
- `b.jpg` — 目标画面(翻转后看到的)

也认 `.png` 和 `.webp`。刷新页面自动生效,不用改代码。

## 两条要求

1. **两张都要有。** 只放一张会被忽略,直接退回占位图 —— 半套素材的效果比占位图更难看。
2. **两张同尺寸,宽高比贴近墙的宽高比。** 墙的宽高比 = `列数 ÷ 行数`(默认 24 ÷ 14 ≈ 1.71,接近 16:9)。比例差太多画面会被拉伸。

## 分辨率怎么选

每一格实际显示的是源图的 `1/列数 × 1/行数`。默认 24×14 的网格下,2048×1200 的源图分到每格只有约 85×85 像素。想让单格细节经得起看,源图给到 4096 宽比较稳。
